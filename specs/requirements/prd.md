# Hello World Webapp

## Problem Statement

There is no minimal web application to confirm that a new web app can be built, signed in to and deployed on the platform end to end.

## Solution

A single-page web app that greets the signed-in user with "Hello, World!" — the smallest working product.

## Actors

- User — anyone who signs in to the app; sees the greeting.
